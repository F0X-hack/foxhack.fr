03 — FLASH

Le flash

Écriture locale depuis le navigateur, sans serveur ni outil installé.

  • Câble USB de données : un câble de charge seule ne monte pas le port série.
  • Branchement direct sur le PC, sans hub ni rallonge.
  • Fermer tout moniteur série qui occupe déjà le port.

  1. Branchez votre ESP32-S2 en USB.
  2. Choisissez l'appareil dans la section 02.
  3. Cliquez sur « Flasher » puis sélectionnez le port série dans la fenêtre.

04 — INSTALLATION MANUELLE

Linux & esptool

Alternative en ligne de commande, sans navigateur.

  1. Téléchargez le firmware (fichiers .bin dans la section 05, même dossier que la commande).
  2. Installez esptool : pip install esptool.
  3. Branchez l'ESP32-S2 et identifiez le port série (/dev/ttyUSB0, /dev/ttyACM0…).
  4. Exécutez la commande en adaptant le port.
Important : remplacez /dev/ttyUSB0 par le chemin réel de votre port. Utilisez dmesg | tail ou ls /dev/tty* pour l'identifier.
Terminal Linux 
esptool.py --chip esp32s2 -p /dev/ttyUSB0 -b 460800 --before default_reset --after hard_reset write_flash 0x0 esp32s2_ducky.bin
En cas de problème — effacement complet

Si la carte ne démarre plus ou refuse le flash, effacez la flash puis relancez l'écriture.

Effacement 
esptool.py --chip esp32s2 --port /dev/ttyUSB0 erase_flash

Cette commande efface aussi le disque et les payloads — sauvegardez vos fichiers DuckyScript avant.
